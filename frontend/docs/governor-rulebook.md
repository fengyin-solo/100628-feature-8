# 调速器油压与导叶开度统一判定口径

> 生效范围：水电站机组运行检修管理平台全模块（调速器页面、检修班组校验待办、继电保护运行台账、运营概览、对账导出）。
> 首版生效：**2026-10-05（v1.0）**。本文件是全平台唯一口径来源，对应代码 `frontend/src/domain/governor/rules.ts`；
> 任何纸面交接不得再另立标准，页面不允许保存第二套结论。

## 1. 判定对象与取值

### 1.1 基础量

| 量 | 符号 | 说明 |
| --- | --- | --- |
| 额定油压 | Pr | 装置铭牌额定压力，默认 2.5 MPa，按装置自带额定值参与比值 |
| 实测油压 | P | 现场表计读取的压力油装置压力（MPa） |
| 导叶开度 / 开度限位 | a / A | 百分比，到顶比 r₁ = a ÷ A |
| 接力器行程 / 行程上限 | s / S | 毫米，到顶比 r₂ = s ÷ S |
| 到顶比 | r | r = max(r₁, r₂)；**导叶开度顶到开度限位与接力器行程到顶，按同一套阈值判定** |

### 1.2 两路读数的先后与冲突（两条路径谁先谁后）

每个量都可能来自两条路径：

1. **交接填报**（值班交接纸上的登记值）；
2. **现场实测**（校验/巡检当场表计值）。

取值顺序固定为：**先取交接填报落库，现场实测后到；同一字段两路都有且数值不一致时，一律以现场实测那一份为准并覆盖填报值。**
全平台（调速器判定、检修待办、继电保护台账、对账导出）统一读仲裁后的这一份取值，每个字段在界面上标注来源（`交接填报` / `现场实测` / `缺值`），
两条路径永远不会各自产出一套等级。

## 2. 等级与建议动作（一次判定同时给出）

油压、开度两路分别判定后，**综合等级取两路最高档**；建议动作由综合等级唯一决定，全平台只存这一份结论。

| 综合等级 | 台账状态 | 建议动作（唯一） |
| --- | --- | --- |
| 正常 | 正常 | 正常运行，按周期巡检 |
| 关注 | **待校验** | 落到检修班组校验待办，安排一次校验并复测油压/开度 |
| 异常 | 异常 | 立即降负荷并通知检修班组到场处理，未消缺前不得并网；停用前继续挂异常账 |
| 严重 | 已停用 | 立即事故停机、切断压油装置并挂牌停用，按事故处理流程上报 |

- 判成「关注/待校验」的调速器自动进入**检修班组校验待办清单**（独立入口 `/governor-todo`），检修班组在自己的入口看到该安排校验的装置。
- 判成「异常/严重」的装置自动镜像到**继电保护运行台账**，异常装置台数两处读到的必须相等。
- 人工挂牌停用的「关注」装置同步移出待办与待校验台数（单列为停用档）；「异常/严重」停用后仍保留在异常台账，台数不丢。

## 3. 油压判定阈值（按额定油压 Pr 的上下限分档）

以 p = P ÷ Pr 判定，上下限全部固定，区间按从小到大第一个命中取值：

| 等级 | 下限（不含） | 上限（含） | 判定条件 |
| --- | --- | --- | --- |
| 严重 | — | 0.80 Pr | p ≤ 0.80（事故低油压**硬上限**，含边界） |
| 异常 | 0.80 Pr | 0.85 Pr | 0.80 < p ≤ 0.85 |
| 关注 | 0.85 Pr | 0.90 Pr | 0.85 < p < 0.90 |
| 正常 | 0.90 Pr | 1.05 Pr | 0.90 ≤ p ≤ 1.05（运行允许上下限） |
| 关注 | 1.05 Pr | 1.10 Pr | 1.05 < p ≤ 1.10 |
| 异常 | 1.10 Pr | 1.15 Pr | 1.10 < p ≤ 1.15 |
| 严重 | 1.15 Pr | — | p > 1.15（过压**硬上限**，不含边界） |

2.5 MPa 额定装置的直观对照：

| 油压区间 (MPa) | 等级 |
| --- | --- |
| ≤ 2.00 | 严重（事故低油压） |
| (2.00, 2.125] | 异常 |
| (2.125, 2.25) | 关注（待校验） |
| [2.25, 2.625] | 正常 |
| (2.625, 2.75] | 关注（待校验） |
| (2.75, 2.875] | 异常 |
| > 2.875 | 严重（过压） |

## 4. 导叶开度 / 接力器行程到顶判定（同一套阈值）

到顶比 r = max(导叶开度 ÷ 开度限位, 接力器行程 ÷ 行程上限)，任一路顶到上限都算数：

| 等级 | 条件 | 含义 |
| --- | --- | --- |
| 正常 | r < 100% | 未顶到限位 |
| 关注 | 100% ≤ r ≤ 102% | **顶到开度限位或接力器行程到顶**，安排校验 |
| 异常 | r > 102% | 越限，立即降负荷处理 |
| 严重 | r > 105% | 越过**硬上限**，立即事故停机 |

开度与行程两路数据全部缺失时，本路不参与定级（等级按油压路），缺失字段进入缺值清单单列。

## 5. 历史油压缺失的补判范围（已定）

历史记录油压值缺失（两路都读不到）时，**不允许按正常放过**：

- 按补判区间 **(0.85 Pr, 0.90 Pr]** 的**从严端**直接补判为「关注 / 待校验」，结论标注 `缺值补判`；
- 装置立即进入检修班组校验待办，现场实测补值并提交校验后按实测比值重新判定，等级随实测结果回落；
- 缺失记录同时进「缺值单列」清单（装置、发生时间、缺失字段、待补测/已补测），不与正常记录混排；
- 油压缺失但到顶比越限的，综合取最高档（可能为异常/严重）。

## 6. 校验提交规则

- 校验必须录入**现场实测三量及其限值**：实测油压、导叶开度/开度限位、接力器行程/行程上限；缺一整笔退回。
- **同一台调速器同一班次只认第一次提交**：以「日期 + 班次」为去重键（如 `2026-10-05|白班 08:00-20:00`），后到的按重复退回，
  不生成新结论、不改变台数，只提示重复。
- 提交后按当前口径用实测值复判：油压恢复正常带则异常等级回落（关注→正常、异常→关注/正常等按实测比值落档），
  待办条数、继电保护台账台数同步更新。
- 每次提交都追加一条校验受理记录（装置、班次、提交人、时间、实测值、复判等级）。

## 7. 阈值换版规则

- 版本只准在 `rules.ts` 的 `THRESHOLD_VERSIONS` 中新增，禁止改旧版本数值。
- 换版时对**所有已判定装置按新口径重算**，逐条追加「换版重算」结论；既有结论**保留当时等级并注明版本**，结论沿革可查、不被覆盖。
- 当前版本号显示在每张判定表、每条结论与每份对账导出里。
- v1.1（演练版，2026-10-05 起可切换）：油压正常带收窄到 0.95 Pr～1.04 Pr，到顶预警线提前到 98%。

## 8. 存量迁移与缺值列示

- 两张纸时代的存量记录，首次进入统一判定域时按**发生时间升序**逐条迁移落库，每条立即按生效口径判定。
- 迁移为整批事务：出现致命错误（如缺装置编号）则整批中止，旧记录保持原样，不允许迁入半截。
- 迁移完成后在页面注明迁移时间、旧记录条数、迁入台数与初始口径版本；缺值记录单独列示。

## 9. 事务与对账

### 9.1 事务原子性

任何写操作（校验提交、换版重算、人工停用、存量迁移）都在一份草稿上完成全部修改，先跑提交前对账再一次性写盘：

- 对账不过或写盘失败 → **整笔退回**，内存缓存与 localStorage 都停在操作前一版，记录里不允许出现中间态；
- 不允许「等级改了但待办没更新」「受理记录写了但结论没复判」之类部分成功。

### 9.2 对账口径（口径与明细清单一起变）

每次提交前与每次页面读取都执行同一份对账，台数取自同一份结论，明细清单随口径同时导出：

1. 调速器异常装置台数 = 继电保护运行台账镜像台数；
2. 待校验装置台数 = 检修班组校验待办条数；
3. 正常 + 待校验 + 异常（含停用未消缺）+ 停用档台数 = 调速器总台数；
4. 缺值单列条数 = 仍带未补缺值的装置台数。

运营概览中调速器行的总数/待处理/异常量、调速器页面统计卡、检修待办页、继电保护页、CSV 导出，读的都是这一份对账结果。
