# 水电站机组运行检修管理平台

面向电站台账、机组运行、调速励磁、主变与闸门、大坝渗流位移监测、机组检修与发电计划的一体化水电站运行检修管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `hydropower-plant-om:entries` 这一项，或调用 `resetModule(模块)`。

## 调速器油压与开度统一判定

交接口径以 [`docs/governor-rules.md`](./docs/governor-rules.md) 为唯一权威（阈值与代码同源）：

- 油压按额定压力 Pn 分四档：**L1 正常** 0.85~1.10Pn、**L2 关注** 0.80~0.85 / 1.10~1.15Pn、
  **L3 待校验** 0.70~0.80 / 1.15~1.25Pn、**L4 危急** <0.70 或 >1.25Pn（绝对上限 1.25Pn，边界就低）。
- 导叶开度顶开度限位/接力器行程到顶走**同一套阈值**：满发顶限位判正常，非满发顶限位判 L3；
  油压、位置同时命中 ≥L3 综合抬为 L4。一次判定同时给等级与建议动作，每台装置只存一份当前结论。
- 取值两条路径：**现场实测（油压表/接力器行程）优先，监控远传次之**；偏差 >5% 以实测为准并挂通道校验。
- 历史油压缺值不填假数，按 L2 档（0.80~0.85Pn 侧）补判、列缺值清单、24h 内补测，不计异常台数。
- L3/L4 自动落「检修待办入口」；校验必须带复测实测值，等级随复测值回落并关闭待办；
  同装置同班次（白班 08-20 / 夜班）只认第一次提交，后到的按重复退回。
- 阈值带版本（v1.0 / v2.0）：换版按新口径重算在运装置，历史结论保留当时等级并注明版本。
- 存量记录按发生时间整批事务迁移，缺值单列；所有写操作先过不变式（异常台数＝检修待办＝保护台账镜像）
  再一次性落库，失败整笔退回，不留中间态。
- 判定领域代码在 `frontend/src/domain/governor/`（规则引擎 + 事务存储），独立持久化键
  `hydropower-plant-om:governor-domain:v1`；行为断言：`npm run verify:domain`。
